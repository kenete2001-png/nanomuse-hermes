# Hermes (français) pour Android

Une seule APK : le vrai **Hermes Agent** de Nous Research tourne sur le téléphone, avec sa mémoire, ses compétences, ses outils, ses routines et son tableau de bord officiel. Il suffit d'ajouter sa clé API.

- Moteur : paquet Android officiel de Nous Research (dépôt APT signé, empreinte de clé vérifiée).
- Terminal : bash et git (paquets Termux officiels, signatures vérifiées).
- Interface : en français, thème bleu nuit inspiré de l'app officielle Hermes Mobile.

Basé sur [LeslieCoding/hermes-android](https://github.com/LeslieCoding/hermes-android) (MIT) et [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) (MIT). Ce n'est pas une application officielle de Nous Research.
