# nanoMuse Hermes

nanoMuse officiel (https://github.com/nano-muse/nanoMuse) + Hermes Agent officiel, exécuté dans Ubuntu 24.04 (PRoot) dans l'app.

Ce dépôt suit les dépôts officiels : à chaque nouvelle version officielle, l'app est reconstruite, signée et publiée dans les Releases. L'app propose alors la mise à jour en un clic, sans effacer l'Ubuntu ni les données.

`ci/signing.tar.gz.gpg` : clé de signature chiffrée (AES-256). La phrase de déchiffrement n'est que dans les secrets Actions.
